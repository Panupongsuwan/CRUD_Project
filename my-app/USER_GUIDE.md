# คู่มือการใช้งานระบบจัดการข้อมูลรถ

คู่มือนี้อธิบายการใช้งานระบบสำหรับห้องปกครองและยาม/รปภ. บนคอมพิวเตอร์และโทรศัพท์มือถือ

## 1. เริ่มต้นใช้งาน

1. เปิดเว็บไซต์จาก URL ที่ผู้ดูแลระบบแจ้ง
2. กรอกอีเมลและรหัสผ่านของบัญชีที่ผู้ดูแลระบบเตรียมไว้ แล้วเลือก **เข้าสู่ระบบ**

ระบบปิดการสมัครสมาชิกด้วยตนเอง บัญชีเดิมยังใช้เข้าสู่ระบบได้ หากเข้าสู่ระบบไม่ได้หรือลืมรหัสผ่าน ให้ติดต่อผู้ดูแลระบบ ระบบจะพาไปยังหน้าที่ตรงกับ role ของบัญชีโดยอัตโนมัติ

### สิทธิ์การใช้งาน

- **ห้องปกครอง:** ดู เพิ่ม แก้ไข ค้นหา และลบข้อมูลรถได้ รวมทั้งดูแดชบอร์ดและประวัติรถเข้า–ออก
- **ยาม/รปภ.:** ดูได้เฉพาะแดชบอร์ดและประวัติรถเข้า–ออก ไม่มีเมนูหรือสิทธิ์เปิดหน้าจัดการรถ เพิ่ม แก้ไข หรือลบข้อมูลรถ

การกำหนด role ทำโดยผู้ดูแลระบบกับบัญชีที่มีอยู่แล้ว ไม่สามารถเลือก role เองจากหน้าล็อกอินได้

## 2. หน้าจัดการข้อมูลรถ

เฉพาะบัญชีห้องปกครองเท่านั้นที่เปิดหน้าจัดการข้อมูลรถได้ หลังเข้าสู่ระบบจะแสดงจำนวนรถทั้งหมด จำนวนยี่ห้อรถ และจำนวนรถที่มีรูปภาพ พร้อมรายละเอียดรถ เจ้าของ และปุ่ม **แก้ไข** กับ **ลบ**

### เพิ่มรถ

1. เลือก **เพิ่มรถ**
2. กรอกข้อมูลที่จำเป็นให้ครบ:
   - **หมวดอักษร:** 2 ตัวอักษร โดยต้องมีอักษรไทยอย่างน้อย 1 ตัว
   - **เลขทะเบียน:** ตัวเลข 1–4 หลัก
   - **จังหวัด:** เลือกจากรายการจังหวัด
   - **ชื่อเจ้าของ** และ **เบอร์โทรศัพท์:** เบอร์โทรยาว 8–30 ตัวอักษร ใช้ตัวเลข ช่องว่าง `+` วงเล็บ หรือขีดกลางได้
   - **ยี่ห้อ** และ **รุ่น:** พิมพ์เพื่อเลือกคำแนะนำ หรือกรอกชื่อเองได้
   - **สีรถ:** เลือกจากรายการสี หากไม่มีสีที่ต้องการ ให้เลือก **สีอื่น ๆ** แล้วระบุสี
3. หากต้องการแนบรูป ให้เลือกไฟล์ `.jpg`, `.png` หรือ `.webp` ขนาดไม่เกิน 5 MB
4. ตรวจสอบข้อมูล แล้วเลือก **บันทึกข้อมูล**

ระบบไม่อนุญาตให้บันทึกข้อมูลที่มีทะเบียน หมวดอักษร และจังหวัดซ้ำกันภายในบัญชีเดียวกัน

### ค้นหารถ

พิมพ์คำค้นในช่อง **ค้นหาทะเบียน ชื่อเจ้าของ หรือรถ** รายการจะกรองทันที โดยค้นหาได้จากหมวดอักษร เลขทะเบียน จังหวัด ชื่อเจ้าของ เบอร์โทร ยี่ห้อ รุ่น หรือสี

### แก้ไขข้อมูลและรูปภาพ

เลือก **แก้ไข** ที่รายการรถ แล้วปรับข้อมูลตามต้องการ:

- หากไม่เลือกรูปใหม่ รูปเดิมจะยังคงอยู่
- หากเลือกรูปใหม่ รูปใหม่จะใช้แทนรูปเดิม
- หากต้องการเอารูปออก ให้เลือก **ลบรูปรถปัจจุบัน**
- เลือกรูปใหม่และเลือกเอารูปเดิมออกพร้อมกันไม่ได้

เลือก **บันทึกข้อมูล** เพื่อยืนยัน หรือ **ยกเลิก** เพื่อปิดแบบฟอร์มโดยไม่บันทึก

### ลบรถ

เลือก **ลบ** ที่รายการรถ แล้วตรวจสอบทะเบียนและจังหวัดในหน้าต่างยืนยัน การลบจะนำข้อมูลรถและรูปที่แนบไว้ออกจากระบบ และไม่สามารถกู้คืนผ่านหน้าจอได้

## 3. แดชบอร์ด

เลือก **แดชบอร์ด** จากเมนูด้านบน

- ห้องปกครองจะเห็นสถิติรถและรายการรถที่เพิ่มล่าสุดไม่เกิน 5 รายการ พร้อมลิงก์กลับไปหน้าจัดการรถ
- ยาม/รปภ.จะเห็นเฉพาะแดชบอร์ดและข้อมูลรถเข้า–ออก ไม่มีรายการรถที่เพิ่มล่าสุด

### ประวัติรถเข้า–ออก

ส่วน **รายการรถเข้า–ออกจากป้ายทะเบียน** เป็นข้อมูลกลางที่ทั้งห้องปกครองและยาม/รปภ.ดูได้ แสดงข้อมูลที่อุปกรณ์ตรวจจับส่งเข้าระบบ เรียงจากรายการใหม่ไปเก่า แสดงหน้าละ 10 รายการ และมีปุ่ม **เก่ากว่า** / **ใหม่กว่า** สำหรับเปิดดูย้อนหลังหรือกลับมารายการใหม่

เหนือประวัติจะแสดงการ์ด **กล้องทางเข้า–ออก (1 กล้อง)** พร้อมรายการตรวจจับล่าสุด หากอุปกรณ์แนบภาพมา ระบบจะแสดงภาพนั้นด้วย ส่วนนี้เป็นภาพ/ข้อมูลจากรายการล่าสุด ไม่ใช่ภาพสดจากกล้อง

หน้าแรกจะโหลดข้อมูลอัตโนมัติทุก 5 วินาที ส่วนหน้าเก่าจะไม่โหลดทับอัตโนมัติ เพื่อให้อ่านประวัติได้ต่อเนื่อง หากต้องการโหลดหน้าปัจจุบันอีกครั้ง ให้เลือก **รีเฟรช**

- ใช้ตัวกรอง **ทั้งหมด**, **เข้า** หรือ **ออก** เพื่อกรองตามทิศทาง
- สถานะ **ในทะเบียน** หมายถึงระบบจับคู่ป้ายทะเบียนกับรถในบัญชีได้ ส่วน **ไม่รู้จัก** หมายถึงยังจับคู่ไม่ได้
- หากรายการมีภาพ ให้เลือก **ดูภาพ** เพื่อเปิดภาพในแท็บใหม่
- ถ้าไม่มีรายการหรือข้อมูลไม่อัปเดต ให้ตรวจสอบการเชื่อมต่ออุปกรณ์กับผู้ดูแลระบบ

บนโทรศัพท์ เมนูและปุ่มหลักมีขนาดเหมาะกับการแตะ แบบฟอร์มเพิ่ม/แก้ไขรถเรียงช่องลงมา และข้อมูลรถแสดงเป็นการ์ด ส่วนรายการตรวจจับจะแสดงเป็นการ์ดที่อ่านได้โดยไม่ต้องเลื่อนตารางแนวนอน พร้อมปุ่มกรองและเปลี่ยนหน้าที่แตะได้สะดวก

## 4. ออกจากระบบและความเป็นส่วนตัว

เลือก **ออกจากระบบ** เมื่อใช้งานเสร็จ โดยเฉพาะเมื่อใช้เครื่องที่ผู้อื่นเข้าถึงได้ อย่าแบ่งปันรหัสผ่านกับผู้อื่น

## 5. แก้ไขปัญหาเบื้องต้น

| อาการ | วิธีตรวจสอบ |
| --- | --- |
| เข้าสู่ระบบไม่ได้ | ตรวจสอบอีเมลและรหัสผ่าน หากลืมรหัสผ่านให้ติดต่อผู้ดูแลระบบ |
| ไม่เห็นเมนูจัดการรถ | ตรวจสอบกับผู้ดูแลระบบว่าบัญชีได้รับ role ห้องปกครองหรือไม่ |
| เปิดหน้าจัดการรถแล้วไม่มีสิทธิ์ | บัญชียาม/รปภ.ดูได้เฉพาะแดชบอร์ด ให้ติดต่อผู้ดูแลระบบหากกำหนด role ผิด |
| บันทึกข้อมูลไม่ได้ | กรอกช่องที่จำเป็นให้ครบ ตรวจรูปแบบหมวดอักษร เลขทะเบียน และเบอร์โทร รวมถึงตรวจว่าทะเบียนซ้ำในจังหวัดเดียวกันหรือไม่ |
| อัปโหลดรูปไม่ได้ | ใช้ไฟล์ JPEG, PNG หรือ WebP ที่มีขนาดไม่เกิน 5 MB |
| ไม่พบรถจากการค้นหา | ลองค้นด้วยทะเบียน ชื่อเจ้าของ เบอร์โทร ยี่ห้อ รุ่น สี หรือจังหวัด |
| รายการตรวจจับขึ้นว่าไม่รู้จัก | ตรวจว่ารถถูกบันทึกในบัญชีนี้แล้ว และข้อมูลป้ายทะเบียนกับจังหวัดตรงกับรถที่ลงทะเบียน |
| หน้าเว็บโหลดข้อมูลไม่ได้ | ลองรีเฟรชหน้าเว็บ หากยังไม่หายให้ติดต่อผู้ดูแลระบบเพื่อตรวจสอบเซิร์ฟเวอร์และฐานข้อมูล |

## สำหรับผู้ดูแลระบบ

บัญชีเดิมจะได้รับ role **ยาม/รปภ.** โดยปริยายหลังอัปเดตระบบ ผู้ดูแลกำหนด role ของบัญชีเดิมได้จาก PowerShell ในโฟลเดอร์ `my-app`:

### บัญชีที่เตรียมไว้

- `admin@gmail.com` — ห้องปกครอง
- `spvc@gmail.com` — ยาม/รปภ.

รหัสผ่านให้ใช้จากข้อมูลที่ผู้ดูแลแจ้งแยกต่างหาก ไม่ควรบันทึกรหัสผ่านไว้ในคู่มือหรือในซอร์สโค้ด

```powershell
npm run set-role -- user@example.com office
npm run set-role -- guard@example.com guard
```

ใช้ `office` สำหรับห้องปกครอง และ `guard` สำหรับยาม/รปภ. คำสั่งนี้เปลี่ยน role ของบัญชีที่มีอยู่เท่านั้น ไม่ได้สร้างบัญชีใหม่ และต้องตั้งค่าเชื่อมต่อฐานข้อมูลใน `.env` ก่อนใช้งาน

ระบบตั้ง `PLATE_OWNER_EMAIL=admin@gmail.com` ไว้เพื่อให้ข้อมูลตรวจจับจับคู่กับรถของบัญชีห้องปกครอง หากเปลี่ยนบัญชีห้องปกครอง ให้ปรับค่านี้ใน `.env` ให้ตรงกับอีเมลบัญชีใหม่ แล้วเริ่มเซิร์ฟเวอร์ใหม่เพื่อให้ระบบโหลดค่าล่าสุด
